# 小炒黄牛肉

> 湘式小炒黄牛肉（吊龙 + 绣球菌），两人份 | 难度：★★☆ | 总时长：约 25 分钟（含腌制）

## 用料表（两人份）

| 食材 | 用量 | 处理 |
| --- | --- | --- |
| 吊龙火锅片 | 200g | 太大片可改刀切小 |
| 绣球菌 | 100g | 撕小朵，水开焯 1 分钟，沥干 |
| 小香芹 | 2–3 根 | 切段 |
| 小米椒 | 3 个 | 斜切段 |
| 泡椒 | 1 个（味重，别多放） | 切碎 |
| 蒜 | 3 瓣 | 切片 |
| 姜 | 3 片 | — |
| 生抽 | 15ml（腌肉 5ml + 炒 10ml） | — |
| 料酒 | 5ml | 腌肉用 |
| 淀粉 | 3g | 腌肉上浆 |
| 白胡椒 | 少许 | 腌肉用 |
| 盐 | 1g | — |
| 鸡精 | 1g | 出锅前放 |
| 食用油 | 25ml（腌肉 5ml + 炒 20ml） | — |

## 步骤

1. 吊龙片加生抽 5ml、料酒 5ml、淀粉 3g、油 5ml、白胡椒少许，抓匀腌 10 分钟（上浆）。
2. 绣球菌撕小朵，水开焯 1 分钟，捞出沥干。
3. 热锅凉油 20ml，**大火**下牛肉快速滑散，**一变色立刻盛出**（火锅片极薄，以秒计）。
4. 余油下姜、蒜、小米椒、泡椒，爆香。
5. 下绣球菌，大火翻炒 1 分钟。
6. 牛肉回锅，加生抽 10ml、盐 1g、鸡精 1g，大火翻匀 30 秒。
7. 关火，下小香芹段，余温翻两下出锅。

## 关键点与易错点

- **嫩牛肉三件套**：上浆 + 大火 + 变色即出（见 [蛋白质热变性](../原理/蛋白质热变性.md)）；火锅片极薄，滑炒以秒计，多炒就老。
- **泡椒味重，1 个就够**（以往实操：2 个已很明显）。
- 绣球菌焯水后务必沥干，否则下锅出水变煮菜。
- 小香芹关火后下，余温断生，保持脆嫩清香。
