# 湘西小炒木耳

> 木耳是主角、肉哨提香，两人份 | 难度：★★☆ | 总时长：约 15 分钟

## 用料表（两人份）

| 食材 | 用量 | 处理 |
| --- | --- | --- |
| 鲜木耳 | 150g（主角） | 洗净撕小朵，焯水 1–2 分钟，沥干 |
| 瘦肉 | 约 50g（提香配菜，待验证） | 切细丝，不腌不浆 |
| 肥肉粒 | 约 50g（待验证） | 切小粒 |
| 杭椒 | 2 根（待验证） | 斜切段（马耳朵） |
| 小米椒 | 2–3 个（待验证） | 斜切段 |
| 蒜 | 2 瓣 | 切末 |
| 姜 | 2 片 | — |
| 生抽 | 10ml | — |
| 盐 | 1g | — |
| 鸡精 | 1g | 出锅前放 |
| 食用油 | 10ml | — |

## 步骤

1. 鲜木耳撕小朵，水开下锅焯 1–2 分钟，捞出沥干。
2. 热锅放油 10ml，下**肥肉粒**小火煸出猪油。
3. 下杭椒、小米椒，煸到微微上色。
4. 火略调小，下姜蒜爆香。
5. 下瘦肉丝，炒到变色。
6. 下木耳，大火翻炒 1 分钟。
7. 加生抽 10ml、盐 1g、鸡精 1g，翻匀出锅。

## 关键点与易错点

- **下料顺序 = 按耐炒程度降序**：肥肉粒（煸油）→ 辣椒（煸香）→ 姜蒜（易糊，下锅前火略调小）→ 瘦肉（快熟）→ 木耳（已焯熟），每样都刚好到位。
- **肥肉粒煸猪油是香气基底**：辣椒和蒜的香气物质多为脂溶性，在猪油里释放更充分（2026-09-20 验证）。
- **肉是提香配菜**：不腌不浆直接炒，口感偏硬有嚼劲（肉哨风格），主角是木耳。想吃嫩肉丝就加回上浆：生抽 5ml + 料酒 5ml + 淀粉 3g 腌 10 分钟（见 [淀粉糊化](../原理/淀粉糊化.md)）。
- **鲜木耳务必先焯水**：含卟啉类光敏物质，充分加热才稳妥；焯过沥干防爆锅。

## 复盘记录

### 2026-09-20
- **调整**：误打误撞改了流程——先下肥肉粒煸油，再下辣椒（杭椒 + 小米椒，斜切段）煸出颜色，再放姜蒜、瘦肉、木耳。肉量减到约 50g 且未腌，木耳当主角。
- **结果**：非常好吃，远超预期，比中午团建吃到的原版更香；肉偏硬但有嚼劲，当配菜正好。
- **分析**：肥肉粒煸出的猪油是脂溶性香气的最佳载体；辣椒先煸释放椒香和微焦香；下料顺序恰好按耐炒程度降序——无意中复刻了农家小炒肉的经典逻辑。
- **瑕疵**：姜蒜还是糊了一点（位置虽靠后但火太猛），幸未影响味道；下次下姜蒜前把火略调小。
- **结论**：新流程转正为菜谱正文。
