# 水煎五花肉

> 水煎五花肉（不带皮、肥煮瘦蒸版），两人份 | 难度：★★☆ | 总时长：约 40 分钟

## 用料表（两人份）

| 食材 | 用量 | 处理 |
| --- | --- | --- |
| 五花肉（不带皮） | 400–500g（整块） | 洗净 |
| 姜 | 3 片 | — |
| 葱 | 1 根 | 切段 |
| 料酒 | 10ml | — |

### 蘸料（蒜泥白肉路线）

| 调料 | 用量 |
| --- | --- |
| 蒜 | 3–4 瓣，捣成泥 |
| 生抽 | 15ml |
| 香醋 | 5ml |
| 香油 | 几滴 |
| 辣椒油 | 按口味（皖北口建议加） |

备选干碟：辣椒面 + 盐 + 花椒面。

## 步骤

1. 五花肉整块洗净，**肥肉面朝下**放入锅中。
2. 加冷水，水位**刚好没过肥肉层**（瘦肉露出水面蒸熟，肉味更浓、不柴，见 [蛋白质热变性](../原理/蛋白质热变性.md)）。
3. 加姜片、葱段、料酒，大火烧开，撇浮沫。
4. 转中小火，**盖盖、不翻面**，水煎约 25 分钟（分层加热：肥肉水煮出油，瘦肉蒸汽焖熟）。
5. 水快干时转小火（水尽油出瞬间溅油最凶）。
6. 水干后，用锅里析出的猪油把另外三面各煎 1–2 分钟至金黄（上色见 [美拉德反应](../原理/美拉德反应.md)）。
7. 取出放 2 分钟，切 5mm–1cm 厚片，配蘸料上桌。

## 关键点与易错点

- **肥肉朝下 + 水只没过肥肉**：肥煮瘦蒸，肥肉出油快、瘦肉不柴肉味浓。
- **中途不翻面**：翻面会把瘦肉按进水里，破坏分层；肥肉始终垫底，水干无缝转油煎。
- **水干前转小火**：残余水分遇热油剧烈飞溅。
- 瘦肉熟度判断：筷子能轻松穿透即可。
