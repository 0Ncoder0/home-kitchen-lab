# 红烧日本豆腐

> 红烧日本豆腐（裹粉煎制版），两人份 | 难度：★★☆ | 总时长：约 20 分钟

## 用料表（两人份）

| 食材 | 用量 | 处理 |
| --- | --- | --- |
| 日本豆腐 | 2 管 | 连包装拦腰切开，轻轻挤出，切 2cm 厚段 |
| 玉米淀粉 | 20g（裹粉）+ 3g（勾芡） | — |
| 蒜 | 2 瓣 | 切末 |
| 葱 | 少许 | 切葱花 |
| 生抽 | 10ml | — |
| 老抽 | 3ml | — |
| 糖 | 3g | — |
| 水 | 100ml（红烧汁）+ 10ml（勾芡） | — |
| 食用油 | 15–20ml | — |

## 步骤

1. 日本豆腐每段两面**裹一层干淀粉**，薄而匀，抖掉浮粉。
2. 调红烧汁：生抽 10ml + 老抽 3ml + 糖 3g + 水 100ml。
3. 平底锅放油 15–20ml，**中火**下豆腐段。
4. **下锅后不要动**，煎 2 分钟等淀粉壳定型，再用铲子配合筷子轻轻翻面，煎到两面金黄硬壳，盛出。
5. 余油爆香蒜末，倒入红烧汁烧开。
6. 豆腐回锅，小火煨 2 分钟——**只晃锅或用铲背轻推，绝不翻炒**。
7. 勾芡：淀粉 3g + 水 10ml 搅匀淋入，汁变稠挂住豆腐（挂汁原理见 [淀粉糊化](../原理/淀粉糊化.md)），撒葱花出锅。

## 关键点与易错点

- **防碎四件套**：切 2cm 厚；裹干淀粉成壳；下锅忍住不动、壳定型再翻；回锅只晃锅轻推。
- **裹粉是核心**：淀粉遇热糊化成硬壳（见 [淀粉糊化](../原理/淀粉糊化.md)），既防碎又能挂汁。
- 中火煎制，火大壳糊内碎。
- 第一次煎碎一两块正常，碎的吸汁更入味，不影响吃。
