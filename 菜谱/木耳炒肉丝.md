# 木耳炒肉丝

> 木耳炒肉丝（鲜木耳版），两人份 | 难度：★★☆ | 总时长：约 25 分钟（含腌制）

## 用料表（两人份）

| 食材 | 用量 | 处理 |
| --- | --- | --- |
| 猪里脊 | 150g | 切细丝 |
| 鲜木耳 | 150g | 洗净撕小朵，焯水 1–2 分钟，沥干 |
| 青椒 | 半个 | 切细丝 |
| 红椒 | 半个 | 切细丝 |
| 蒜 | 2 瓣 | 切末 |
| 姜 | 2 片 | — |
| 生抽 | 15ml（腌肉 5ml + 炒 10ml） | — |
| 料酒 | 5ml | 腌肉用 |
| 淀粉 | 3g | 腌肉上浆 |
| 盐 | 1g | — |
| 鸡精 | 1g | 出锅前放 |
| 食用油 | 20ml（腌肉 5ml + 炒 15ml） | — |

## 步骤

1. 肉丝加生抽 5ml、料酒 5ml、淀粉 3g、油 5ml，抓匀腌 10 分钟（上浆）。
2. 鲜木耳撕小朵，水开下锅焯 1–2 分钟，捞出沥干。
3. 热锅凉油（15ml），下肉丝**快速滑散**，一变白色立刻盛出（八九成熟）。
4. 锅里余油，下姜蒜爆香 2–3 秒，下青红椒丝翻炒几下。
5. 下木耳，大火翻炒 1 分钟。
6. 肉丝回锅，加生抽 10ml、盐 1g、鸡精 1g，大火翻匀 30 秒出锅。

## 关键点与易错点

- **鲜木耳务必先焯水**：鲜木耳含卟啉类光敏物质，充分加热才稳妥；焯过沥干也防止下油爆锅。
- **肉丝嫩 = 上浆 + 变色即出**：淀粉浆在肉表面形成保护膜（见 [淀粉糊化](../原理/淀粉糊化.md)），减少受热失水（见 [蛋白质热变性](../原理/蛋白质热变性.md)）；回锅只炒 30 秒，久炒必老。
- **肉丝先出再回锅**：滑炒类标准动作，保证每样食材刚好熟。
- 油稍多是这道菜「油润感」的来源，家里做 15ml 即可。
